# NewsScope: News Text Mining System

## Project Overview
A text mining system designed to analyse news articles using machine learning and natural language processing techniques.

## Dataset
The dataset has 4 categories:
- World
- Sports
- Business
- Sci/Tech

## Main Features
- News classification
- News clustering
- Topic modelling

## Technologies
- Python
- NLTK
- Scikit-learn
- Pandas
- Matplotlib
- Gensim
